The funniest honest error message an appliance could show, written for make.fun's "The Funniest Honest Appliance Error" bounty.

## The line

> Error 404: Sock not found. It is in the drum. It has always been in the drum.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because the laugh comes out of the truth of the fault, not a pun bolted on. Every household knows the mystery: a sock goes into the washing machine and only one comes out. The machine finally admits what we all suspected — it never lost the sock at all, it kept it, and the second sentence quietly upgrades the crime from a mistake to a policy. The error code is the format a real machine would use, the confession is the joke, and the deadpan repetition ("It has always been in the drum") is the machine refusing to apologise. A washing machine that gaslights you about laundry is exactly the appliance we all live with. One line, 77 characters, well inside the 200-character gate.

## The joke, beat by beat

1. **"Error 404"** — the machine reports the sock the way a server reports a missing page: a real format, instantly familiar.
2. **"Sock not found"** — the fault itself, stated plainly. Every household has lived this exact error.
3. **"It is in the drum"** — the first twist: the sock was never lost, the machine knew where it was.
4. **"It has always been in the drum"** — the second twist: this was never a mistake. The machine kept it, and it is not sorry.
